HIT KAT — PWA package

Files for free hosting on GitHub Pages. Upload the CONTENTS of this folder to the root of a public GitHub repository, then enable Settings > Pages > Deploy from a branch > main / root. Open the published https URL in Safari on iPhone, tap Share, then Add to Home Screen.

The service worker caches the app shell for offline loading after the first successful visit. Workout data uses browser local storage and stays associated with this site/origin. Export a backup from inside the app before changing hosting/domain.

Note: iOS may suspend timers when the app is backgrounded or the screen is locked; sound/timer behavior should be tested on the actual iPhone. This is a web app, not an App Store native app.
